# Accessibility

CapacityAvailability is a PHP library and does not ship a user-facing interface.
We aim to make its documentation, code examples, and contribution workflows
clear and accessible.

Documentation uses headings, descriptive links, and text-based examples.
Accessibility of any UI built using this package remains the responsibility
of the consuming application.

To report an accessibility barrier in this repository, open an issue or email
**alkinbg@gmail.com**.
